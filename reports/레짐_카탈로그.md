# 레짐 카탈로그

_2026-11-25 작성. 레짐을 이름(코드)으로 불러 여러 매매법에 얹어 보기 위한 목록. 새 레짐을 시험하면 **실패한 것도** 여기에 적는다._

## 1. 레짐이란

**"지금 시장이 어떤 상태인가"를 몇 칸으로 나눈 라벨.** 사고팔라는 말은 하지 않는다 —
기존 매매법의 **강도**(매수 크기 · 분할수 · 매도 비율 · 보유 기한)를 상태에 따라 바꾸는 데 쓴다.

좋은 레짐의 조건
1. 상태별로 수익 분포가 실제로 다르다 (→ 레짐별 일평균 수익 · 일샤프부터 확인)
2. 자주 뒤집히지 않는다 (매일 바뀌면 잡음)
3. 미래 정보를 쓰지 않는다 (판정일 종가 확정 후 → 다음 기간에 적용)

## 3. 레짐별 상세

### V1 — 변동성 레짐 (표준편차 기반) ✅

```
변동성 = STDEV(SOXX 최근 20거래일 일간수익률) × √252
백분위 = 최근 756거래일 변동성 중 오늘 값보다 낮은 날의 비율
방향   = 이번 월말 변동성 > 직전 월말 변동성 ? 상승 : 하락
위험 : 상승 & 백분위 ≥ 70%   |   안정 : 하락 & 백분위 < 50%   |   승부 : 그 외
판정 : 매월 마지막 거래일 → 다음 달 전체
```

- 코드: `dss_engine.vol_regime_table()` · `vol_regime_months()` · `load_regime_prices()` (전략과 무관하게 재사용)
- 위험 달은 200개월 중 47개월(약 23%), 평균 1.4개월 연속
- 결과 (Calmar, 2010-03 ~ 2026-11)

| 매매법 | 위험 달 규칙 | 기준 → 적용 | 판정 |
|---|---|---|---|
| DSS 공격형 | 12분할 · 공세 보유 5일 | 1.13 → 1.49 | ✅ 공격형V |
| 표준편차 균형형 | 매도 100% · 비중 50% 상한 | 0.98 → 1.18 | ✅ 균형형V |
| 표준편차 공격형 | 〃 | 0.97 → 1.10 | ✅ 공격형V |
| 표준편차 안정형 · Ultra-Safe · Sonic | 〃 | 구간 최소 미달 / 폭 작음 | △ |
| 듀얼스나이퍼 5종 | 배율 · 분할 · 티어 · 보유일 749조합 | +0.02~0.08 | ❌ |

- 통하는 곳: 물량을 쌓아 오래 들고 가는 전략. 안 통하는 곳: 회전이 빠른 전략(위험 달이 가장 잘 버는 달)
- 상세: `261124_변동성레짐_가이드.md`

### V2 — 변동성 빠른 판정 ❌

V1 과 같은 변동성을 주간(금요일 → 다음 주) · 전일 백분위 · 5일 변동성으로 판정.
DSS 는 월간보다 나쁘거나 비슷, 듀얼스나이퍼는 잡음 수준. 더 좋아 보이는 조합은 거래일 절반을 반만 투자한 것(레버리지 축소)이었다.
→ **판정을 빠르게 한다고 좋아지지 않는다.** (가이드 2절 · 11절)

### V3 — 목표 변동성 배율 (사용 중)

```
배율 = min(1, 목표σ ÷ 최근 4일 일간수익률 σ)      (전일 기준)
```

상태를 나누지 않고 변동성에 반비례해 매수 금액을 연속으로 줄인다. Camarilla 돌파 실험(`_cam_*.py`)의 기본 구성(목표 0.030).
LOC 평균회귀 매매법(DSS · 표준편차)에는 시험하지 않았다.

### A1 — TR(ATR) 백분위 + 단기 추세 △

```
TR     = max(고가−저가, |고가−전일종가|, |저가−전일종가|)
ATR%   = 30일 평균 TR ÷ 종가
스킵   = ATR% ≥ 최근 252일의 70분위  AND  종가 < 30일 이동평균      (전일 기준 → 오늘 매수 안 함)
```

- 코드: `_cam_atr_filter.py` (Camarilla 돌파, SOXL)
- 결과 — 스킵일 21.5%

| 기간 | 베이스 CAGR / MDD / Calmar | + A1 |
|---|---|---|
| 전체 2010~2026 | 53.4% / -37.6% / 1.42 | 50.0% / -28.1% / **1.78** |
| 전반 2010~2018 | 57.5% / -25.7% / 2.24 | 44.0% / -28.1% / **1.57** ↓ |
| 후반 2019~2026 | 48.9% / -37.6% / 1.30 | 57.0% / -24.3% / **2.35** |

- 전반에서 나빠지므로 "모든 구간 통과" 기준으로는 **미통과**. 후반(2020·2022·2026 급락)에서만 크게 번다
- V1 과의 차이: 표준편차는 종가만 보고, TR 은 **장중 고저·갭**을 본다 → 하루짜리 갭 급락에 더 민감. 단 자기 종목(3배) 기준 · 매일 판정이라 잡음이 많다
- '매수를 멈춘다' 방식이다 — DSS 에서는 멈추는 것보다 줄이는 쪽이 나았다

### A2 — TR(ATR) 백분위 단독 (미검증)

V1 의 변동성 자리에 `기초지수(SOXX) 20일 ATR%` 를 넣고 나머지(백분위 · 방향 · 월말 판정)는 그대로.
"표준편차 대신 TR 을 쓰면 위험 달이 달라지는가"를 보는 가장 싼 실험 — 위험 달이 V1 과 대부분 겹치면 버린다.

### T1 — 이동평균 위/아래 ❌

```
허용 = 전일 종가 ≥ N일 이동평균
```

| 매매법 | 필터 | 결과 |
|---|---|---|
| DSS 공격형 | 이동평균 하락 시 매수 축소 | Calmar 개선 없음 |
| Camarilla (SOXL) | SOXL > SMA100 / 150 / 200 | 1.42 → 1.33 / 0.98 / 0.70 |
| 〃 | SPY > SMA200 · QQQ > SMA200 | 1.42 → 1.10 / 1.32 |

전체 기간에서 베이스를 넘는 것이 없다 (`_cam_regime_filter.py`, 가이드 3절). 수익이 줄어드는 폭이 낙폭 감소보다 크다.
→ 단순 "선 위/아래" 는 SOXL 계열에 맞지 않는다.

  2. **2026 폭락을 빼면 사라진다** — ~2025년 말: 균형형 1.40 → 1.43 (CAGR −10%p) · 공격형 1.41 → 1.39 · DSS 1.38 → 1.43
  3. **아래 경계에 뾰족하다** — −30% 를 −25% 로 옮기면 0.95~1.11 로 기준 수준 (월말 낙폭 −25~−30% 인 몇 달이 전부)
  4. 무작위 달 300회 대비 Calmar 상위 4~7% — V1(표준편차에서 상위 7~8%, 큰 낙폭 평균은 0%)보다 나을 것이 없다
  5. 폭락 칸(< −30%)에서 줄이는 규칙은 전부 무효·악화 — "급락 뒤에는 멈추지 말 것" 과 같은 결론
- **결론** — 낙폭 깊이는 변동성 레짐에 없는 새 정보를 주지 않는다. 채택하지 않는다

## 4. 새 레짐을 시험하는 순서 (고정)

1. **판정 함수 하나**로 정의 — 날짜 → 상태. 전일까지의 확정 종가만 사용
2. **레짐별 일평균 수익 · 일샤프** — `regime_daily_profile_2026-11.py` 방식. 상태 간 일샤프 차이가 없으면 여기서 중단
3. **크기에만 적용** — 매수 금액 · 분할수 · 매도 비율 · 보유 기한. 모드(방향)에는 섞지 않는다. 멈추지 말고 줄인다
4. **통과 기준** — 전체 → 앞/뒤 절반 → 봉인 구간(2024-01~) → 4년 구간 최소값 → 기준값 ±10%p. 전부 통과해야 채택
5. **우연 점검** — 같은 개수의 무작위 달 300회 대조, 상시 적용 대조 (레버리지를 낮춘 것뿐인지)
6. **이 문서에 기록** — 통과 · 실패 모두. 레짐을 많이 시험할수록 하나쯤 우연히 통과하므로 실패 기록이 분모가 된다
7. 채택하면 주문표 = 엔진 체결 대조, 적용 시작일(`vreg_from`), 주문표·텔레그램 안내 줄 (가이드 5~8절)

## 5. 조합할 때

- 같은 계열끼리(V1 + X1, V1 + A2)는 대부분 같은 날을 가리킨다 — 위험 달 겹침 비율을 먼저 본다
- 다른 계열(V1 + D1, V1 + T2)은 조합 가치가 있을 수 있으나, 레짐 2개 × 상태 3개면 칸이 9개라 칸당 표본이 급감한다
- 기준 종목은 **기초지수(1배)** — 3배 ETF 자체 지표는 같은 정보의 3배일 뿐이다 (A1 은 예외적으로 자기 종목 기준이었음)
